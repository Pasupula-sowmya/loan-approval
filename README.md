
# Loan Approval Prediction using Machine Learning

This project predicts whether a loan should be approved or not using machine learning techniques.
It is based on historical loan applicant data and follows a complete ML lifecycle:
data collection, preprocessing, model training, evaluation, and conclusion.

## Algorithms Used
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine

## Tools & Libraries
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

## Best Model
Random Forest Classifier
